# Cueback demo script — target 110 seconds

Record the real app on the device used for the demo. Use only a local sample bank or material you have permission to show. Do not present a staged screen as an app screenshot. Complete the Test Store setup and iPad QA first; cut any segment that does not work on the recorded build. Keep the final export below 120 seconds and use no unlicensed music or trademarks.

| Time | Screen/action | Spoken narration |
| --- | --- | --- |
| 0–12 s | Open Cueback and show the presentation list. | “While preparing for the Wharton Global High School Investment Competition, I could analyze investments, but answering unexpected English questions on the spot was harder.” |
| 12–29 s | Open a presentation and show an expected question and its answer script. | “Cueback lets me write the questions I expect and the exact English answers I want to give. These are my words, prepared before the presentation.” |
| 29–50 s | Enter Live Q&A, tap Listen, ask an English question, tap Stop. | “During Q&A, Cueback transcribes the question. Speech recognition may use the device's system service.” |
| 50–68 s | Show semantic candidates, selected answer, and Korean question translation. | “An on-device MiniLM model ranks the closest prepared questions. When confidence is high, Cueback brings up my answer. If it is uncertain, I can select a candidate myself.” |
| 68–79 s | Show the answer script clearly and scroll if needed. | “It never invents an answer for me.” |
| 79–91 s | Show the free limit and open Cueback Pro from the library screen. | “Free includes one presentation and five questions. Pro gives me room to prepare as many as I need.” |
| 91–103 s | Show the SDK price, tap Test purchase, choose Success in the RevenueCat Test Store modal. | “This is a RevenueCat Test Store purchase. No real money is charged.” |
| 103–110 s | Show Pro active and the new-item action unlocked. | “RevenueCat confirms the Pro entitlement, and Cueback unlocks the larger question library.” |

**VERIFY:** Native purchase, entitlement, and device footage before recording. If Test Store cannot be configured, do not simulate a success screen; record the truthful configuration state and mark the submission demo incomplete.
